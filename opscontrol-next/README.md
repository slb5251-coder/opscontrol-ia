# OPSControl IA Next

Nova interface criada do zero e isolada do sistema atual.

## Stack
React, TypeScript, Vite, Headless UI, Motion e Supabase.

## Execução
```bash
npm install
npm run dev
```

Copie `.env.example` para `.env.local` e informe as credenciais públicas do Supabase. Não publique chaves privadas.
